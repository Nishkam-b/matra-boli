# Matra Boli by Nishtek

**Your video. Every Indian language.** A free, in-browser caption studio for Indian creators.

Live: **https://nishtek.in/matra-boli/**

- Transcribes Hindi, Hinglish, English and Indian languages with Whisper large-v3 turbo and a dedicated Hindi→Hinglish model, running locally in the browser with Transformers.js (WebGPU). No uploads, no accounts, no API keys.
- Animated Reels-style captions: 13 styles, 12 word animations, 23 font pairings, and a 130-font Google Fonts library with Hindi font support.
- Timeline editor, translation (NLLB-200), and MP4 / SRT / VTT export.

It's a static site with no build step: GitHub Pages serves this folder as-is.
